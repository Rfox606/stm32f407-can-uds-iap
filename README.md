# STM32F407 CAN/UDS 在线固件升级系统

> **M0阶段：可移植的固件更新核心、Flash抽象、CRC校验及主机端测试。STM32底层驱动、CAN/ISO-TP/UDS接入、实物联调尚未完成。**

本项目探索在STM32F407上通过经典CAN与UDS实现应用固件更新。第一版为**单APP槽位 + 常驻Bootloader**，重点研究启动流程、Flash扇区管理、固件完整性、通信状态机及升级失败后的重新刷写。

## 架构

```text
PC/Linux升级工具（待实现）
  → 经典CAN / ISO-TP / UDS（待接入）
  → STM32F407 Bootloader
      ├─ CAN接收及会话管理（待实现）
      ├─ 固件更新核心 + CRC32 + 固件有效性（M0已实现）
      ├─ Flash抽象接口（M0已实现；STM32驱动待实现）
      └─ APP启动跳转（待实现）
  → APP业务演示（待实现）
```

## 阶段

- M0：代码架构、更新核心、模拟Flash及单元测试。
- M1：STM32F407工程、链接脚本、Flash驱动、Bootloader与APP跳转。
- M2：bxCAN、ISO-TP、UDS刷写流程及异常状态机。
- M3：上位机升级工具、数据交互及故障场景测试。
- M4：故障排查记录、回归验证和技术面试准备。

**验证边界：** 当前主机端测试不代表真实硬件CAN、Flash或断电恢复已实测。单APP槽升级失败后可重新刷写，不等于自动回滚。详细设计和源码以仓库中的文档与各模块为准。
