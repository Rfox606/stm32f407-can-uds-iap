# CAN、ISO-TP与UDS协议约定

**M2已提供实际协议代码和主机端测试，详见[《M2协议实现与验证》](12_M2_协议实现与验证.md)。**

采用经典CAN标准帧，500 kbit/s；诊断仪请求ID为0x7E0，Bootloader响应ID为0x7E8。单APP槽；物理收发器未实测。

实现服务为0x10、0x22、0x34、0x36、0x37、0x31、0x11、0x3E；不支持0x27安全认证。

**特有约定：** `0x34 00 44`后为4字节地址、4字节长度；`0x37`之后附带4字节大端CRC32和4字节大端版本号，是本项目定义的厂家扩展参数。

`0x36`在协议层使用8位块序号，在更新核心使用32位实际字节偏移。重复块只有在读回字节完全一致时才能重新确认。

Flash擦除按扇区推进，前后发出`7F 34 78`等待响应；整包CRC例程同样采用`7F 31 78`延迟确认。

当前结论以ARM交叉编译、软件测试为依据；实际Flash耗时、CAN错误恢复和实物启动行为尚未验证。
