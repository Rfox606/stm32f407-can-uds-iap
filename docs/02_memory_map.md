# STM32F407VG Flash分区方案

目标芯片为1 MB Flash的STM32F407VG。STM32F407采用单物理Bank，下列区域属于软件分区。

| 扇区 | 地址 | 大小 | 功能 |
|---|---|---:|---|
| 0～3 | 0x08000000～0x0800FFFF | 64 KB | 常驻Bootloader |
| 4 | 0x08010000～0x0801FFFF | 64 KB | 镜像元数据 |
| 5～11 | 0x08020000～0x080FFFFF | 896 KB | 单APP槽位 |

元数据单独占据64 KB扇区会浪费一定空间，但能单独擦除，便于第一阶段的异常恢复设计。正式实现前必须结合实际Bootloader体积和链接结果复核。

## 元数据结构：iap_image_record_t
偏移0：image_size；偏移4：image_crc32；偏移8：version；偏移12：record_crc32；偏移16：magic。总长20字节。

镜像大小须为8～896 KB。初始MSP必须4字节对齐并位于普通SRAM地址区间；复位入口必须设置Thumb位且位于APP镜像范围内。启动还需要验证完整固件的CRC32。

## 提交规则
开始升级前先擦除元数据；固件写入完成后从Flash重新计算CRC32；最后单独写入magic有效标志。任何步骤失败都不能让不完整固件获得有效标志。

## 注意
- CRC能够检测偶然损坏，但不能替代数字签名。
- 目前的链接脚本文件只是MEMORY片段，不是可以直接链接的STM32工程。
- 真实Flash擦写会涉及F407单Bank代码取指阻塞、中断时序和看门狗，需在M1/M2进一步处理。
- 本项目不能将单槽失败后重新刷写称为“自动回滚”。
