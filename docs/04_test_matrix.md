# 测试矩阵与证据边界

## M0已完成的9个主机端测试

| 场景 | 预期结果 | 结果 |
|---|---|---|
| 空元数据启动 | 进入恢复模式 | 通过 |
| CRC标准向量“123456789” | 得到0xCBF43926 | 通过 |
| 正常升级 | 写入、校验、提交后选择APP | 通过 |

## 本地执行
\`\`\`bash
cmake -S . -B build
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/iap_core_test
\`\`\`

每次测试记录日期、提交号、输入、预期、实际结果、运行命令及日志位置。不要将主机端模型结果填写为板级实测。
